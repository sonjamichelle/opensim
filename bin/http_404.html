404 – Endpoint Not Available

You reached an OpenSim administrative or monitoring endpoint that is either disabled, misconfigured, or not currently exposed.

This is NOT a user error

This page exists for grid operators and administrators. Viewers do not use this endpoint.

Common reasons you are here

  • Monitoring or WebStats is disabled
  • The simulator is stalled or unhealthy
  • The endpoint was enabled without understanding its purpose
  • You followed outdated documentation or forum advice

What you should do next

  1. Check simulator logs before restarting anything
  2. Verify Monitoring and WebStats configuration
  3. Confirm the region heartbeat is advancing
  4. Review recent load, content, or configuration changes
